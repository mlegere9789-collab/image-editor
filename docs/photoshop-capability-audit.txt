Absolutely. I’m going to treat “every single thing Photoshop can do” broadly: not just the obvious toolbar tools, but also Adobe’s named commands, panels, layer systems, selection/masking systems, filters, color systems, automation, AI/Firefly features, typography, 3D-adjacent workflows, file handling, measurement, compositing, video, plugins, and production features.
One important caveat: there is no finite Adobe list called “everything Photoshop can do.” Photoshop is extensible, version-dependent, and many capabilities are combinations of tools rather than standalone features. Adobe’s current desktop documentation itself spans hundreds of individual help topics. The list below therefore aims to be a near-comprehensive functional encyclopedia using Adobe’s terminology, rather than pretending that undocumented combinations or every third-party plugin can be enumerated. Adobe’s current 2026 documentation confirms many of these systems and continues to add AI features. (Adobe Help Center)

Adobe name: Scale

Menu: Edit > Transform > Rotate

Adobe name: Skew
Slants the selected content horizontally or vertically.
It is useful for creating an oblique/slanted appearance without applying a full perspective transformation.
Menu: Edit > Transform > Skew

Adobe name: Warp
Bends and reshapes content using a customizable grid.

Important correction to the methodology
This batch exposes something important about the earlier estimate: 450 does not mean we are almost finished with literally everything Photoshop can do.
Adobe's current desktop documentation contains additional systems that we have deliberately not expanded yet, including Neural Filters, Camera Raw, painting/brush systems, retouching tools, text and typography, shapes and paths, layer systems, Smart Objects, layer styles, automation/actions, file import/export, artboards, grids/guides, measurement, animation/video, metadata, plugins, scripting, and collaboration/cloud functionality. Also, Adobe explicitly distinguishes Smart Filters from ordinary filters: filters applied to Smart Objects can remain editable and removable rather than permanently altering the underlying pixels. (Adobe Help Center)
So after 450, I would not claim that only 50 things remain. The original “10 batches” estimate was a workload approximation, not a genuine Adobe feature count.
